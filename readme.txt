Tutti i form di Elementor Pro in un unico pannello: destinatari, thank you page, webhook, richieste ed email personalizzate.

== Description ==

Gestisce i form di Elementor Pro senza aprire Elementor. Richiede Elementor Pro (email personalizzate: 4.0.3 o successivo). Compatibile con Multisite.
